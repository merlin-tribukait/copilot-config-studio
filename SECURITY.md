# Security policy

Copilot Config Studio is an early-stage project and does not yet have a
released support policy. Security reports are still welcome.

Please do not disclose suspected vulnerabilities in public issues or pull
requests. Use GitHub's
[private vulnerability reporting](https://github.com/merlin-tribukait/copilot-config-studio/security/advisories/new)
when available for this repository. If that option is unavailable, contact a
repository maintainer privately through GitHub to arrange a secure channel.

Include the affected version or commit, impact, and reproducible steps. Do not
include real API keys, credentials, private prompts, or other user data in a
report. Please allow maintainers time to investigate and prepare a fix before
public disclosure.

Until releases are published, use the latest `main` branch at your own risk.
